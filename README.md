# Khaled Ahmed — نسخة سطح المكتب

نسخة الديسكتوب من تطبيق Khaled Ahmed: نفس الموقع والتصميم والخطوط وقاعدة البيانات، في نافذة مستقلة مع تثبيت وتحديث تلقائي.

## التحميل
من صفحة الإصدارات (Releases):
- ويندوز: `KhaledAhmed-Setup.exe`
- ماك: `KhaledAhmed-mac.dmg`
- لينكس: `KhaledAhmed-linux.AppImage` أو `KhaledAhmed-linux.deb`

## التحديث
التطبيق يتحقق من الإصدارات الجديدة في هذا المستودع تلقائيًا ويثبّتها عند إعادة التشغيل.

## البناء
أي دفع إلى main يشغّل GitHub Actions: يبني ويندوز وماك ولينكس وينشر إصدارًا جديدًا `v1.0.<رقم التشغيل>` مع ملفات `latest*.yml` الخاصة بالتحديث التلقائي.

متغيّرات اختيارية في Settings ثم Secrets and variables ثم Actions ثم Variables:
- `SITE_URL`: رابط الموقع المستخدم في روابط المشاركة داخل التطبيق.
- `WEB_CLIENT_ID`: لا تحتاجه نسخة سطح المكتب (تسجيل Google يتم عبر نافذة المتصفح الداخلية).
